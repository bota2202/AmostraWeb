# 02 - Glossário

| Termo | Descrição |
|--------|-----------|
| Pedido | Registro do envio realizado pelo vendedor para um cliente, podendo conter uma ou mais amostras. |
| Amostra | Produto individual enviado ao cliente para avaliação comercial, pertencente a um pedido. |
| Administrador | Usuário com acesso total ao sistema, responsável pelo gerenciamento de usuários, permissões e configurações. |
| Gestor | Usuário responsável por acompanhar os vendedores vinculados ao seu estabelecimento. |
| Representante | Usuário responsável pelo cadastro e acompanhamento dos pedidos e das amostras sob sua responsabilidade. |
| Estabelecimento | Unidade da empresa à qual um usuário pertence. |
| ERP | Sistema corporativo utilizado pela empresa para gerenciar clientes, produtos e demais informações operacionais. |
| Auditoria | Registro de todas as ações relevantes realizadas no sistema. |
| Status | Situação atual de uma amostra durante seu ciclo de vida. |
| Dashboard | Painel inicial do sistema contendo indicadores, estatísticas e informações relevantes sobre pedidos e amostras. |
| Permissão | Autorização concedida a um usuário para executar determinadas ações dentro do sistema. |
| Log | Registro cronológico das ações realizadas por usuários ou pelo próprio sistema. |
